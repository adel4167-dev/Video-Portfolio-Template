Overview

This guide explains where to find and edit key elements of your portfolio site. Each section includes:

  • Visual Example - What the element looks like
  • File Location - Which file contains the code

Getting Your Vimeo ID: Your Vimeo URL looks like https://vimeo.com/123456789 - the ID is 123456789. The thumbnail URL is automatically generated: https://vumbnail.com/YOUR_ID.jpg

Cut and paste entire video card blocks to change their order in the grid.

js/video-modal.js

Customize Vimeo Player Settings

js/config.js Lines 35-37 
// Video modal
modal: {
    vimeoParams: 'autoplay=1&badge=0&autopause=0'
}
Available Vimeo Parameters:
  • autoplay=1 - Start playing automatically
  • badge=0 - Hide Vimeo badge
  • autopause=0 - Don't auto-pause when switching tabs
  • loop=1 - Loop the video
  • muted=1 - Start muted

Site Configuration

js/config.js

The config.js file contains all major behavioral settings in one place:

All Configuration Options

Setting Default Description
header.showThreshold 300 Scroll position (px) to show sticky header
header.socialIconsOffset 150 Offset from bottom of about section (px)
gallery.autoScrollSpeed 0.8 Auto-scroll speed for photo gallery
videoEffects.horizontalScale 0.98 Scale for adjacent video cards on hover
videoEffects.horizontalOpacity 0.85 Opacity for adjacent video cards on hover
modal.vimeoParams autoplay=1... Vimeo embed parameters

Example: Change When Header Appears

header: {
    showThreshold: 500,  // Change from 300 to 500
    socialIconsOffset: 150
}

JavaScript Files

Script Organization

File Purpose Key Functions
config.js Central configuration All site settings
header.js Sticky header behavior Show/hide header on scroll
video-modal.js Video popup Open/close modal, embed video
video-effects.js Video card hover effects Scale/fade adjacent cards
video-categories.js NEW Category filtering Filter videos by category
gallery.js Photo gallery Auto-scroll, navigation
Important: Scripts must be loaded in order! config.js should always load first, as other scripts depend on it.

Script Loading Order (in HTML)

<!-- External libraries first -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>

<!-- Config must load before other custom scripts -->
<script src="js/config.js"></script>

<!-- Then other scripts (order doesn't matter for these) -->
<script src="js/header.js"></script>
<script src="js/video-effects.js"></script>
<script src="js/video-modal.js"></script>
<script src="js/video-categories.js"></script> <!-- NEW -->
